# Cybersecurity Learning Portfolio

A working portfolio of my cybersecurity studies and practice. I’m building practical foundations in networking, Linux, Python, and security testing while learning to document technical work clearly and responsibly.

## Focus areas

- Cybersecurity fundamentals
- Networking and TCP/IP
- Linux and command-line workflows
- Python scripting
- Defensive thinking and responsible disclosure

## Selected projects

- [Vibe Scanner WSL](https://github.com/sharifjonovbexruzbek60-cmyk/Vibe-Scanner-WSL) — networking concepts and controlled lab practice.
- [Python Port Scanner](https://github.com/sharifjonovbexruzbek60-cmyk/python-port-scanner) — introductory Python and TCP exercises.
- [Password Security Analyser](https://github.com/sharifjonovbexruzbek60-cmyk/password-security-analyser) — a local educational password-characteristics exercise.
- [Vulnerability Research](https://github.com/sharifjonovbexruzbek60-cmyk/Vulnerability-Research) — defensive security notes and remediation guidance.

## Working principles

I use controlled labs and systems I own or have explicit permission to assess. I aim to stay within scope, avoid exposing sensitive information, and communicate security observations responsibly. The projects are works in progress and reflect my current learning.
